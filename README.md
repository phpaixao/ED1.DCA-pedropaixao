# 📊 Estrutura de Dados I - Implementações em Go

Este repositório contém implementações desenvolvidas durante a disciplina de **Estrutura de Dados I (ED1)**.

O foco do projeto é a implementação prática das principais estruturas de dados e algoritmos fundamentais utilizando **Go (Golang)**, com ênfase em desempenho, organização e boas práticas de código.

---

## 📂 Estrutura do Repositório

O projeto está organizado por temas:

```
ED1.DCA-pedropaixao/
│
├── Algoritmos de Ordenação/
├── Arvores/
├── Estruturas de Dados/
├── Lista de Exercicios (implementações)/
├── Tabela Hash/
└── README.md
```

---

## ⚙️ Conteúdos Implementados

### 🔹 Estruturas de Dados

* Listas encadeadas
* Pilhas (Stacks)
* Filas (Queues)
* Estruturas com alocação dinâmica

### 🔹 Árvores

* Percursos (pré-ordem, em-ordem, pós-ordem)
* Travessia em nível (level-order)
* Operações básicas em árvores

### 🔹 Tabela Hash

* Implementação de tabela hash
* Tratamento de colisões
* Operações de inserção, busca e remoção

### 🔹 Algoritmos de Ordenação

* Bubble Sort
* Counting Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort

### 🔹 Algoritmos de Busca

* Busca linear
* Busca binária

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/phpaixao/ED1.DCA-pedropaixao.git
```

2. Acesse a pasta desejada:

```bash
cd ED1.DCA-pedropaixao/Algoritmos\ de\ Ordenação
```

3. Execute o programa:

```bash
go run main.go
```

> 💡 Caso prefira compilar:

```bash
go build -o programa
./programa
```
